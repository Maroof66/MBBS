# Consolidation of Memory

### Headings

* Definition
* Role of hippocampus
* Role of medial temporal lobe
* Storage of long-term memory
* Intercortical transfer of memory

---

## 1. Definition

* **Consolidation** = process by which newly acquired memory is converted into **permanent long-term memory**.

## 2. Role of Hippocampus

* **Hippocampus plays an important role in consolidation** of memory.
* Consolidation is strengthened by **emotional association** with the learning experience.
* Hippocampus is important for **formation of long-term declarative memory**.
* However, hippocampus is **not required for subsequent retrieval** of established long-term memory.

## 3. Role of Medial Temporal Lobe

* **Medial temporal lobe**, especially:

  * Hippocampal cortex
  * Parahippocampal cortex
* → important for formation of **long-term declarative memory**.

## 4. Storage of Long-term Memory

* Once consolidated, long-term memories are stored in **various areas of neocortex**.
* Different components are stored in corresponding cortical areas:

  * **Visual memory → Visual cortex**
  * **Auditory memory → Auditory cortex**
* Established memories can later be recalled by **association with related sensory experiences**.

## 5. Intercortical Transfer of Memory

* Memory is transferred between cerebral hemispheres through:

  * **Corpus callosum**
  * **Anterior commissure**
  * **Posterior commissure**
* Interruption of these commissural connections → **impaired transfer of memory between hemispheres**.

---

## Flowchart

**Newly acquired memory**
↓
**Hippocampus + medial temporal lobe**
↓
**Consolidation**
↓
**Permanent long-term memory**
↓
**Various areas of neocortex**
↓
**Retrieval by association**

### ⭐ Key points to remember

**Hippocampus → Consolidation**

**Medial temporal lobe → Formation of long-term declarative memory**

**Neocortex → Long-term storage**

**Corpus callosum + commissures → Intercortical transfer**
