## Gemini Flashcard Prompt
``` Generate a comprehensive hierarchical flashcard deck from the provided notes.

IMPORTANT:
These flashcards are for MBBS university examinations, where answers are written under headings. The objective is not merely to memorize isolated facts but to reconstruct the complete short note or long answer.

Follow this exact hierarchy:

LEVEL 1 – Structure
• Ask for all the main headings of the topic.
• Example:
  - State the headings of Prostate.
  - Enumerate the headings under Control of Muscle Tone.

LEVEL 2 – Heading Recall
For every heading, create one flashcard asking only that heading.
Examples:
- Describe the location of the prostate.
- Describe the relations of the prostate.
- Explain blood supply of the prostate.

LEVEL 3 – Subheading Recall
If a heading contains subheadings, create flashcards for each.
Examples:
- Anterior relations of prostate.
- Posterior relations.
- Venous drainage.
- Lymphatic drainage.

LEVEL 4 – Important Facts
Create flashcards for:
• Definitions
• Classifications
• Enumerations
• Important values
• Important exceptions
• Important clinical correlations
• Functions
• Differences
• Tables
• Mnemonics

LEVEL 5 – Integration
Generate flashcards that connect different headings.
Examples:
- Differentiate venous drainage and lymphatic drainage.
- Which relations are clinically important?
- Which branches arise from the first part of maxillary artery?

Rules:
1. Follow the hierarchy strictly.
2. Do NOT skip headings.
3. Do NOT generate duplicate flashcards.
4. Keep one concept per flashcard.
5. Use the exact terminology used in the notes.
6. Preserve the order of headings as given in the notes.
7. Do not invent information not present in the notes.
8. Whenever the notes contain a diagram, create a flashcard asking what structures should be labelled in that diagram.
9. If a topic naturally forms a flowchart or sequence, generate recall cards for the sequence.
10. Prioritize exam-writing recall over trivia.

The output should feel like reconstructing the complete university answer from memory, beginning with the headings and progressively drilling down into the details.
```
