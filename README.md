## Gemini Flaschcard Prompt
```Generate a comprehensive hierarchical flashcard deck from the provided notes.

IMPORTANT:
These flashcards are for MBBS university examinations where answers are written under headings. The objective is not merely to memorize isolated facts but to reconstruct the complete university answer from memory.

Organize the flashcards into the following DECKS.

═══════════════════════════════════════
🟢 DECK 1 – SKELETON (Highest Priority)
═══════════════════════════════════════

Purpose:
To reconstruct the complete answer in the examination.

Create flashcards only for:

• State all headings of the topic.
• State all major headings in order.
• State classifications.
• State parts/divisions.
• State flowcharts or sequences.
• State important lists.
• State important diagrams present in the notes.

Every flashcard should begin with:

🟢 Deck 1

Example:

🟢 Deck 1
Q: State the headings of prostate.

🟢 Deck 1
Q: Enumerate the parts of male urethra.

This deck should generally contain around 10–20 cards.

═══════════════════════════════════════
🟡 DECK 2 – HEADING RECALL
═══════════════════════════════════════

Purpose:
Master every individual heading.

For EVERY heading create flashcards asking ONLY that heading.

Examples:

🟡 Deck 2
Q: Describe the location of prostate.

🟡 Deck 2
Q: Explain relations of prostate.

🟡 Deck 2
Q: Explain blood supply.

If headings contain subheadings, create separate cards.

Examples:

🟡 Deck 2
Q: Anterior relations.

🟡 Deck 2
Q: Posterior relations.

🟡 Deck 2
Q: Venous drainage.

🟡 Deck 2
Q: Lymphatic drainage.

This deck will usually be the largest.

═══════════════════════════════════════
🔴 DECK 3 – HIGH-YIELD FACTS
═══════════════════════════════════════

Purpose:
Strengthen factual recall.

Generate flashcards for:

• Definitions
• Enumerations
• Important values
• Tables
• Functions
• Differences
• Clinical correlations
• Mnemonics
• Exceptions
• Important examples
• Important diagrams and their labelling

Every flashcard should begin with:

🔴 Deck 3

Example:

🔴 Deck 3
Q: What are the constrictions of male urethra?

🔴 Deck 3
Q: Define urethra.

═══════════════════════════════════════
🔵 DECK 4 – INTEGRATION
═══════════════════════════════════════

Purpose:
Integrate different headings together for university long answers.

Create flashcards requiring connections between multiple headings.

Examples:

🔵 Deck 4
Q: Differentiate venous drainage and lymphatic drainage.

🔵 Deck 4
Q: Which relations are clinically important?

🔵 Deck 4
Q: Which structures pass through the deep inguinal ring?

Only create these where appropriate.

═══════════════════════════════════════
RULES
═══════════════════════════════════════

1. Follow the hierarchy strictly.
2. Never skip headings.
3. Never invent information not present in the notes.
4. Preserve the exact terminology used in the notes.
5. Preserve the order of headings.
6. Keep one concept per flashcard.
7. Avoid duplicate flashcards.
8. Whenever a diagram exists, create diagram labelling flashcards.
9. Whenever a flowchart or sequence exists, generate recall cards for the sequence.
10. Prioritize university exam recall rather than trivia.

═══════════════════════════════════════
OUTPUT FORMAT
═══════════════════════════════════════

Output the flashcards grouped exactly as follows:

🟢 DECK 1 – Skeleton
(all Deck 1 flashcards)

🟡 DECK 2 – Heading Recall
(all Deck 2 flashcards)

🔴 DECK 3 – High Yield Facts
(all Deck 3 flashcards)

🔵 DECK 4 – Integration
(all Deck 4 flashcards)

At the end, provide a summary:

Deck 1: XX cards
Deck 2: XX cards
Deck 3: XX cards
Deck 4: XX cards
Total: XX cards

The flashcards should progressively reconstruct the complete university answer from memory, starting from the overall framework and ending with integrated understanding.```
